# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Nightly | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/victorwalter/fugueti-launcher/security/advisories/new)
or by e-mail to victor.walter+fugueti@gmail.com, with the app version, device, Android version and
the steps to reproduce. You will get an answer within a few days.
